# TO2RENT — Полноценный веб-сайт аренды недвижимости

Современная платформа для поиска, просмотра и онлайн-бронирования элитной недвижимости (квартиры, апартаменты, загородные дома и коттеджи). Проект включает полноценный **бэкенд на C# (ASP.NET Core 9.0)** и модернизированный **интерактивный фронтенд**.

---

## 🚀 Быстрый запуск

### Вариант 1: Через командный файл (в 1 клик)
Просто запустите файл:
```cmd
run.bat
```
Скрипт автоматически запустит сервер на C# и откроет браузер по адресу `http://localhost:5000`.

### Вариант 2: Через терминал (.NET CLI)
```bash
cd Backend
dotnet run
```
После запуска откройте в браузере: **[http://localhost:5000](http://localhost:5000)**

## 🏗 Архитектура и технологии

### Бэкенд (C# / .NET 9):
- **Фреймворк:** ASP.NET Core 9.0 Web API (RESTful архитектура).
- **База данных:** SQLite (`Backend/to2rent.db`) с использованием **Entity Framework Core 9**.
- **Автоматический Seed:** При первом запуске база автоматически наполняется всеми квартирами, коттеджами, отзывами, заявками и менеджерами.
- **Статический сервер:** Бэкенд сам раздает файлы фронтенда (`PhysicalFileProvider`), обслуживая сайт и API на едином порту `5000`.
- **CORS:** Включен `AllowAll` для поддержки как совместного запуска, так и независимого запуска через Live Server.
- **Документация API:** Интерактивный интерфейс **Scalar API Reference** доступен по адресу **[http://localhost:5000/scalar/v1](http://localhost:5000/scalar/v1)**.

### Фронтенд:
- **HTML5 / CSS3 / SCSS / JavaScript (ES6+)**.
- **REST API клиент:** `TO2RENT/JS/api-client.js` для асинхронного взаимодействия с бэкендом.
- **Интерактивный модуль:** `TO2RENT/JS/app-interactive.js` (модальные окна, уведомления-тосты, валидация, калькулятор бронирования).
- **Динамический каталог:** `apartments.js` и `houses.js` с мгновенной фильтрацией, поиском и сортировкой.
- **Отзывы в реальном времени:** `comments.js` с динамической загрузкой и онлайн-публикацией.
- **Панель управления (Админка):** `admin.html` + `admin.js` для полного контроля над заявками, клиентами, базой недвижимости и модерацией.

## 📱 Функциональные возможности сайта

1. **Главная страница (`index.html`):**
   - Интерактивный слайдер фотографий в шапке (Terr1, Terr2, Terr3).
   - Поисковая строка: поиск по городу с перенаправлением в каталог с примененным фильтром.
   - Популярные объекты с прямым переходом к карточкам.
   - Блок менеджеров (Макс, Анна) с кнопкой **«Связаться»**, открывающей модальное окно персонального запроса.
   - Баннер промо-коттеджа с кнопкой **«Забронировать»**.
   - Форма быстрого вопроса в подвале сайта с отправкой в базу данных.

2. **Каталог квартир (`Html-Pages/apartments.html`) & домов (`Html-Pages/houses.html`):**
   - Интерактивная панель фильтров:
     - Поиск по ключевым словам и названию;
     - Выбор города (Москва, Минск, Лондон, Лос Анджелес);
     - Фильтр по комнатам (для квартир) или этажам (для домов);
     - Диапазон цен (От / До);
     - Сортировка (Сначала дешевле, Сначала дороже, По площади);
     - Кнопка сброса фильтров.
   - Клик по фотографии разворачивает интерактивную шторку с описанием объекта.
   - Кнопка **«Подробнее»** ведет на детальную страницу объекта.
   - Кнопка **«Забронировать»** открывает модальное окно оформления брони.

3. **Модальное окно бронирования:**
   - Автоматически подставляет выбранный объект и его цену.
   - Поля: Имя клиента, Телефон, Email, Дата заезда, Дата выезда, Количество гостей, Комментарии.
   - **Динамический расчет стоимости:** автоматически считает количество ночей и итоговую сумму!
   - Валидация данных и отправка в C# бэкенд (`POST /api/bookings`).
   - Красивое всплывающее уведомление (Toast) с номером зарегистрированной брони.

4. **Страница отзывов (`Html-Pages/comments.html`):**
   - Загрузка реальных отзывов из SQLite базы данных.
   - Отображение звездного рейтинга (1–5 звезд), имени автора и даты.
   - Форма отправки отзыва: отправляет отзыв на сервер и мгновенно добавляет его в список без перезагрузки страницы.

5. **Панель управления / Админка (`Html-Pages/admin.html`):**
   - Доступна через кнопку «Админка» в меню навигации.
   - **KPI аналитика:** общее число объектов, активные бронирования, выручка по подтвержденным сделкам, новые вопросы, средний рейтинг.
   - **Управление бронированиями:** просмотр всех заявок, смена статуса (*Ожидает / Подтверждено / Отменено / Завершено*), удаление.
   - **Управление вопросами клиентов:** просмотр сообщений из подвала и запросов к менеджерам, отметка об обработке.
   - **Управление каталогом:** список объектов, кнопка **«+ Добавить объект»** с модальной формой добавления новой недвижимости в базу, удаление объектов.
   - **Модерация отзывов:** просмотр и удаление спама.

## 🔌 Спецификация REST API (C#)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/properties` | Получение списка недвижимости с фильтрами (`type`, `city`, `minPrice`, `maxPrice`, `minRooms`, `search`, `sort`) |
| `GET` | `/api/properties/{id}` | Получение информации об объекте по ID |
| `POST` | `/api/properties` | Добавление нового объекта в каталог |
| `PUT` | `/api/properties/{id}` | Редактирование объекта |
| `DELETE` | `/api/properties/{id}` | Удаление объекта из базы данных |
| `GET` | `/api/properties/popular` | Топ популярных объектов для главной страницы |
| `GET` | `/api/properties/featured` | Промо-объект для баннера |
| `GET` | `/api/bookings` | Список всех бронирований (фильтр по `status`) |
| `GET` | `/api/bookings/{id}` | Получение бронирования по ID |
| `POST` | `/api/bookings` | Оформление новой брони |
| `PATCH`| `/api/bookings/{id}/status` | Изменение статуса брони (*Pending, Confirmed, Cancelled, Completed*) |
| `DELETE`| `/api/bookings/{id}` | Удаление брони |
| `GET` | `/api/reviews` | Список одобренных отзывов |
| `POST` | `/api/reviews` | Добавление нового отзыва |
| `DELETE`| `/api/reviews/{id}` | Удаление отзыва (модерация) |
| `GET` | `/api/inquiries` | Список вопросов и запросов клиентов |
| `POST` | `/api/inquiries` | Отправка вопроса / запроса на обратную связь |
| `PATCH`| `/api/inquiries/{id}/status` | Отметка о рассмотрении (*Processed / New*) |
| `DELETE`| `/api/inquiries/{id}` | Удаление запроса |
| `GET` | `/api/stats` | Сводная аналитика для панели управления |
| `GET` | `/scalar/v1` | Интерактивная документация и тестирование API |
